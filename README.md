## goblog介绍


> goblog基于go语言开发的一个简约版个人博客系统,基于Golang语言编写,后端基于了Beego的web框架,目前具备博文系统最基础的功能模块.基本上是一个拿来即用的个人博文平台,只需要部署一个mysql数据存储服务,即可作为个人博文的发布平台使用.
> 如果这个项目对你有帮助，欢迎 Star：https://github.com/liangyd1024/goblog
